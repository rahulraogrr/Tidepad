# Tidepad code review — 2026-09-27

Scope: all app sources under `Tidepad/` (~3,000 lines of Swift), plus a skim of `Tests/` and `Documentation/`. Nothing was built or run for this review. Line numbers refer to the files as they were on 2026-09-27. Limitations already listed in `Documentation/SearchMilestone.md` (large-file editing, NSFilePresenter, regex timeouts) are not repeated here.

## High

### 1. Choosing "Don't Save" when closing the window does not discard anything
`App/TidepadApp.swift:31`, `Documents/DocumentManager.swift:152`

`windowShouldClose` calls `confirmCloseAll()`. That only asks the user about each document; it never removes them. The window closes, but the dirty documents stay in `manager.documents`. `applicationShouldTerminateAfterLastWindowClosed` isn't implemented, so the app keeps running. Two things go wrong:
- Quitting afterwards asks about the same documents again.
- Reopening the window from the Window menu shows them still dirty.

Fix: once the user confirms, either terminate the app (return `true` from `applicationShouldTerminateAfterLastWindowClosed`) or clear `documents` and the sessions after a successful `confirmCloseAll()`.

### 2. Saving replaces the file instead of updating it in place
`Documents/TextFileService.swift:64`

`data.write(to:options: .atomic)` writes a temp file and renames it over the target. As a result:
- Scripts lose their executable bit, because the new file gets default permissions.
- ACLs and xattrs are dropped.
- A symlink is replaced by a regular file, so the real target is never updated.
- Hard links break.

For a Notepad++-style editor that people will use on shell scripts and dotfiles, this matters. Fix: resolve symlinks first (`resolvingSymlinksInPath()`), then write to a temp file and use `FileManager.replaceItemAt(_:withItemAt:)`, which preserves metadata. Or copy the original `posixPermissions` back onto the new file after writing.

### 3. Apostrophes start multi-line strings in YAML, HTML and XML
`Syntax/LineLexer.swift:82` and `:116`

Any `'` outside JSON opens a string. At the end of the line, the quote state is reset for most languages, but not for `isMarkup`, `.sql` or `.yaml`. So an ordinary line like `description: Don't use this` in YAML, or `<p>It's here</p>` in HTML, colours **the rest of the file** as a string until another apostrophe turns up. Markdown also colours the rest of the line after "don't".

Fix:
- In markup, only treat quotes as strings when `state.inTag`.
- In YAML, only open a quote when it starts a scalar (after `: `, `- `, `[`, `{` or at the start of the line).
- In Markdown, don't treat `'`/`"` as string delimiters at all.

Add fixtures for all three to `SyntaxChecks`.

### 4. Legacy 8-bit files (Windows-1252 / Latin-1) are likely to fail to open
`Documents/TextFileService.swift:37–43`

If a file has no BOM and isn't valid UTF-8, the code falls back to `String(contentsOf:usedEncoding:)`. That call mostly detects BOMs and the `com.apple.TextEncoding` xattr, and for a typical CP-1252 file it throws. The user then gets an error alert instead of the file. It also reads the file a second time. Please verify with a fixture containing `0xE9` (é in CP-1252).

Fix: if the fallback throws, decode as `.windowsCP1252`, or `.isoLatin1`, which accepts every byte sequence. Record that encoding on the document so saving round-trips it. Find in Files skips these files silently (`FindInFilesService.swift:74–77`); consider matching the open path.

## Medium

### 5. The search panel floats above other apps
`Search/SearchController.swift:73`

The panel has `level = .floating` and `hidesOnDeactivate = false`. Switching to another app leaves the Find window on top of that app's windows. Fix: keep the default `hidesOnDeactivate = true`, or drop the floating level.

### 6. Save All opens a Save panel for every blank Untitled tab
`Documents/DocumentManager.swift:108`

The filter is `hasUnsavedChanges || fileURL == nil`. A new, untouched Untitled tab (the app creates one at launch) therefore triggers a Save dialog. Cancelling returns early and leaves `selectedID` on that tab instead of restoring `original`. Fix: filter on `hasUnsavedChanges` only, and restore the selection with `defer`.

### 7. Caret moves are O(line length)
`Editor/EditorSession.swift:213–214`

Every selection change builds `substring(start..<offset)` and calls `.count` (grapheme walk) to get the column. On a minified 5–20 MB single-line JSON or log file, each arrow key allocates and scans megabytes. The selection count (`LineIndex.characters(in:)`, single-line path) has the same cost.

Fix:
- Use an ASCII fast path: if the line is ASCII (you already track `nonASCII` in `parse`; keep a per-line flag), column = UTF-16 distance.
- Otherwise cache the (offset, column) pair from the last caret position on the same line and count only the difference.

### 8. The lexer allocates in its innermost loop
`Syntax/LineLexer.swift:25–28`, `:61`, `:101`

`matches(_:at:)` creates two arrays on every call: `Array(text.utf16)` and the slice copy. Inside block comments and markup comments it runs once per UTF-16 unit, sometimes twice. The string-delimiter check copies a slice per unit, and the literal list `["true", …]` is rebuilt for every word.

Fix: use precomputed `static let` `[UInt16]` patterns, compare element by element without copying, and make the literals a `static let Set`. This should noticeably reduce the lex time behind the 1 MB syntax cap.

### 9. Find in Files walks `.git`, `node_modules` and other hidden directories
`Search/FindInFilesService.swift:32–33`

The heuristic rejects the binary objects, but each file still costs an open plus an 8 KB read. In a real repository this dominates run time and fills the "skipped" count. Fix: add `.skipsHiddenFiles` by default (Notepad++ makes hidden folders opt-in), and optionally a default exclude list.

### 10. Hardening: a document's text depends on a weak reference to the editor's storage
`Editor/EditorSession.swift:80`, `Models/EditorDocument.swift:42, 58`

`attachStorage` clears `storedText`, and `read` is `{ [weak storage] in storage?.string ?? "" }`. Today a session lives as long as its tab, so this is safe. But if a session is ever released while its document is still open (a future memory-saving change, or a bug in `retainDocuments`), `document.text` silently becomes `""`, and Save writes an empty file.

Fix: add a `detachStorage()` that copies the live text back into `storedText`. Call it from the session's teardown, or from `EditorSessionStore` before a session is dropped.

## Low

11. **Inconsistent URL comparison.** `Search/SearchController.swift:252` compares `fileURL == url` directly. Everywhere else, including `acceptOpened`, uses `standardizedFileURL`. If the paths differ only in form, the "open document differs" check can be skipped and `acceptOpened` then selects an existing tab.
12. **⌘+ needs Shift on US keyboards.** `.keyboardShortcut("+")` (`Commands/ViewCommands.swift:14`) only fires with Shift+=. Most Mac apps also accept ⌘=.
13. **Replace doesn't move on when nothing matches.** When the selection isn't a match, Replace only shows "No matching text selected" (`Search/SearchController.swift:178`). In Notepad++, Replace moves to the next match in that case.
14. **Zoom and font changes touch every open document.** `applyDisplayOptions` sets `.paragraphStyle` across each session's whole storage (`Editor/EditorSession.swift:149`), so zooming costs O(total bytes of all open tabs). Consider applying it lazily to non-visible sessions.
15. **Test harness code ships in Release.** `Tests/AppPerformanceValidation.swift` isn't wrapped in `#if DEBUG`, and `TidepadApp.swift:52` calls it unconditionally. It's inert without the environment variables, but it is compiled into Release.
16. **Menu arrangement depends on English titles.** `NativeMenuCoordinator` finds menus by their English titles. Under a localised system it quietly stops reordering. This is fine for now, but worth a comment.

## What's solid

- Search is careful. Every async path checks the generation, revision and selection before applying anything. Work is cancelled through `withTaskCancellationHandler`. Replace All is a single undo group with a bounded plan.
- The dirty-state tracking via `editingState`/`savedState` plus undo registration handles undo-back-to-saved correctly.
- `LineIndex.applyEdit` reparses neighbouring lines, so CR/LF joins and splits at edit edges are handled. The UTF-16 offsets line up with AppKit.
- The syntax layer is cleanly separated from AppKit. Painting is limited to the visible range, and stale results are rejected by revision.
- Known limitations are documented honestly, which made this review faster.

## Suggested order

Fix 1, 2 and 3 first (user-visible, small changes). Then do 4, with a CP-1252 fixture, and 6. Items 7 and 8 are the next performance wins before starting the large-file work.
