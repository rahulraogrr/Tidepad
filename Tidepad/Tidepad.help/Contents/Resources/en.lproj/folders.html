TidePad Help

Work with a folder

TidePad isn't an IDE, but it can show a whole project, so you can find and open its files quickly.

Open a folder

Choose File > Open Folder (⇧⌘O). The folder appears in the sidebar on the left, and TidePad opens it again next time. Close it with File > Close Folder.

The sidebar

Show or hide the sidebar with View > Show Sidebar (⌘B). Drag its edge to make it wider or narrower. Click a file to open it. The sidebar updates by itself when files are added, removed or renamed.

Files that most projects ignore, such as .git, node_modules and build output, and anything listed in the project's .gitignore, are hidden. To see them, choose View > Show Ignored Files.

Create, rename and remove

Use the buttons at the top of the sidebar to make a new file or folder, or Control-click an item for more: New File, New Folder, Rename, Move to Trash, Reveal in Finder, Copy Path and Open in Terminal.
