Find and replace

Find⌘F
Find Next / Previous⌘G / ⇧⌘G
Replace⌘H
Find in Files⇧⌘F
Go to Line⌘L

Find in Files

Find in Files searches every file in a folder and its subfolders. When a project folder is open, it searches that folder. Click a result to open the file at that line.

Find All in Current Document

Search > Find All in Current Document lists every match in the current tab.

Go to Line

Enter a line number to move the cursor there.
