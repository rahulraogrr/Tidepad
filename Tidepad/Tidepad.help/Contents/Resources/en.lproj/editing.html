Duplicate Current Line⌘D
Delete Current Line⇧⌘K
Move Line Up / Down⌥⌘[ / ⌥⌘]

These work on every line in the selection.

Tools

The Tools menu formats JSON (⌃⌥J), XML (⌃⌥X) and SQL (⌃⌥S), converts the selection to UPPERCASE, lowercase or Title Case, sorts lines and removes duplicate lines. Sorting and formatting work on the selection, or the whole document when nothing is selected. Each tool can be undone in one step.

On-device AI

On macOS 26 or later with Apple Intelligence turned on, Tools > On-Device AI (also in the right-click menu) uses the language model built into your Mac. Nothing you select leaves your Mac, and it works offline.

  • Explain says what the selected code, log line or error means. With nothing selected it explains the line with the caret.
  • Summarise sums up the selection, or the whole document (in a large file, the lines on screen).
  • Rewrite fixes spelling and grammar, makes the selection shorter, or turns it into a list. Check the result, then click Replace; Undo puts the original back.
  • Write Regular Expression turns a description, such as "lines with an email address", into a regular expression; Use in Find puts it in the Find panel.

The answer appears in a small panel as it's written; Stop ends it early. The model reads up to about 8,000 characters at a time, so for longer text, select the part you need. If Apple Intelligence is off or still downloading its model, the panel says so.

Languages and colouring

TidePad colours Swift, Java, Python, JSON, XML, SQL, JavaScript, TypeScript, HTML, CSS, YAML and Markdown, chosen by the file's extension. To choose another language for a tab, use the Language menu; Use File Extension goes back to the automatic choice.

Links

Web addresses and email addresses are underlined. ⌘-click one to open it.

Display

Zoom with ⌘=, ⌘− and ⌘0. The View menu shows or hides line numbers, the status bar and the toolbar, and turns word wrap on or off. Choose TidePad > Settings (⌘,) to set the appearance (System, Light or Dark), the editor font and size, the tab width, and which bars and line numbers are shown; changes apply at once. Restore Defaults puts the editor settings back. The Settings menu has the same window as Preferences, and quick choices for the theme, font and tab size.
