Tidepad Help

Use Claude Code with Tidepad

Claude Code can connect to Tidepad the way it connects to VS Code. Once connected, it knows which folder you have open, which files are open in tabs and what text you've selected, and it shows the changes it wants to make for you to review.

Connect

In Tidepad's terminal panel, run claude; it connects by itself, and the panel shows “Claude Code connected”. In another terminal app, run /ide in Claude Code and choose Tidepad.

Review changes

When Claude Code wants to change a file, Tidepad opens a window showing the change. Click Accept to apply it or Reject to turn it down, and Claude Code carries on from there.

Share a selection

Select text in a tab, and Claude Code can see it, so you can ask about “this function” or “these lines”.
