Tidepad Help

Use the terminal

Tidepad has terminals in a panel at the bottom of the window, as VS Code does. They run your usual shell, so your settings, aliases and tools all work.

Show and hide

Choose Tools > Terminal (⌃`). A new terminal starts in the open project folder, or else the current file's folder. Hiding the panel keeps the terminals running. Drag the top edge of the panel to resize it.

More than one terminal

Click + in the panel, or choose Tools > New Terminal, to open another terminal in its own tab. Closing a tab ends its shell; closing the last one hides the panel. The ↻ button restarts the shell in the current tab.

Select, copy and paste

Drag to select text; double-click selects a word and triple-click a line. Copy with ⌘C, paste with ⌘V, and select everything with ⌘A. Some programs, such as Claude Code and vim, use the mouse themselves; hold ⌥ while dragging to select text in them.

⌘K clears the terminal. Scroll up to see earlier output.

Keys

⌘← / ⌘→Start / end of the line
⌥← / ⌥→Previous / next word
⌘⌫Delete to the start of the line
⌥⌫Delete the previous word
⇧↩ or ⌥↩A new line in Claude Code's prompt

VoiceOver

VoiceOver reads the terminal as a text area: you can move through the visible lines by line, word and character, and VoiceOver reads a command's output as it arrives. Programs that fill the whole screen, such as vim and less, aren't read automatically; use VoiceOver's reading commands to read their screen.
