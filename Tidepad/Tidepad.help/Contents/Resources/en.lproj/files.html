TidePad Help

Open, save and keep files

Open and save

Choose File > Open (⌘O) to open files; each opens in its own tab. File > New (⌘N) makes an Untitled tab. Save with ⌘S, or choose Save As (⇧⌘S) to save a copy under a new name. Save All saves every tab with changes.

You can also drag files onto TidePad, or open them from Finder with Open With > TidePad.

Tabs

Double-click the empty part of the tab bar, or click + at its right end, to open a new Untitled tab. The ▾ button beside it lists every open tab, so you can jump to one that doesn't fit in the bar, and × closes the current tab. Close a tab with ⌘W. File > Close All and Close Other Tabs close several at once, asking about any unsaved changes.

Print

Choose File > Print (⌘P) to print the current tab. It prints in the editor's font with the Light theme's syntax colours, whatever theme is on screen, and puts the file name and page numbers at the top and bottom of each page. To save a PDF instead, choose Save as PDF from the PDF menu in the print panel. File > Page Setup (⇧⌘P) chooses the paper size and orientation.

Recent files and folders

File > Recent Files and Recent Folders list what you opened lately. Each menu has a Clear command.

Unsaved work is kept

When you quit, TidePad keeps your tabs, including Untitled tabs and changes you haven't saved. They come back, still unsaved, the next time you open TidePad, with the same tab selected and the cursor where you left it. TidePad also saves a backup every few seconds while you type, so little is lost if the Mac restarts unexpectedly.

Your settings, such as the theme, font, tab size and which bars are shown, are remembered too.

Changes made by other apps

If another app changes a file you have open and you haven't edited it, TidePad reloads it. If you have unsaved changes, TidePad asks what to do.

Large files

Files of 64 MB or more, such as big logs, data exports or database dumps, open in TidePad's large-file view. They open almost at once whatever their size, even 500 MB, because TidePad reads only the part on screen and keeps your edits as small changes on top of the file. You can scroll, go to any line (⌘L), type, paste, delete, undo and redo, find and replace (⌘F, then ⌘G), including regular expressions and whole words, count matches, and save. The status bar shows "large file".

Replace All changes up to 100,000 matches at a time, and you can undo it in one step. In a large file a regular-expression match can be up to 64 KB long.

Large files are coloured like other files, from the language in the Language menu. In a very big file, colours far down may take a few seconds to settle when a comment or string spans many lines, while TidePad works through the file in the background. Lines longer than 16 KB aren't coloured.

In this version, large files have no word wrap, Find All isn't available, and neither are the Encoding menu and Tools. Large files must be UTF-8.

Unsaved changes to a large file are kept when you quit, like any tab's: TidePad remembers just your changes, not a copy of the file. If another app changes the file before you open TidePad again, your changes no longer fit it, and TidePad tells you.

Encodings

TidePad detects each file's encoding when it opens it and shows it in the status bar. The Encoding menu ticks it too.

Convert: choose another encoding in the Encoding menu (or under Other Encodings) to save the document in it from now on. The text stays the same. If some characters can't be written in that encoding, for example Chinese text in Western (Windows 1252), TidePad says so and changes nothing.

Reopen with Encoding: if a file's text looks wrong, its encoding was probably guessed wrongly. Choose Encoding > Reopen with Encoding and the right one to read the file again. Any unsaved changes are lost, so TidePad asks first.

Line endings

The status bar shows whether the file uses Unix (LF), Windows (CRLF) or classic Mac (CR) line breaks. To change every line break, choose Encoding > Line Endings; this can be undone. Return types the document's line break, so a Windows file stays a Windows file.
