Tidepad Help

Tidepad is a fast, native Mac text editor in the spirit of Notepad++, with a project sidebar, a built-in terminal and a connection to Claude Code.

  • Open, save and keep filesTabs, printing, recent files, unsaved work kept between launches, changes made by other apps.
  • Work with a folderOpen a project folder, browse it in the sidebar, create and rename files.
  • Edit textLine tools, formatting, case, sorting, languages, links, zoom and display settings.
  • Find and replaceFind, Replace, Find in Files and Go to Line.
  • Use the terminalTerminals in a panel at the bottom of the window, as in VS Code.
  • Use Claude Code with TidepadLet Claude Code see your folder, tabs and selection, and review its changes.
  • Keyboard shortcutsEvery shortcut in one list.
